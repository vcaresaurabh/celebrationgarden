# celebrationgarden
Premier Wedding Banquet Venues

Blueprint: "Eternal I Do" - Wedding Banquet Website
Core Philosophy: Less is more. Use ample white space, high-quality imagery, a limited color palette, and elegant typography to create a feeling of sophistication and calm.

1. Design & Aesthetic (The "Beautifully Managed" Part)
Color Palette:

Primary: Off-White / Cream (#F8F5F0)

Secondary: Soft Sage Green (#A4B8A4) or Dusty Rose (#D4A5A5)

Accent: Warm Gray (#6B6262) or Gold Foil (as an image element, not a web color)

Text: Charcoal Gray (#2E2E2E)

Typography:

Headings: A elegant serif font (e.g., Cormorant Garamond, Playfair Display).

Body Text: A highly readable sans-serif (e.g., Lora, Cormorant, Crimson Pro) or a clean sans-serif (e.g., Inter, Lato, Open Sans).

Imagery:

Hero Image: A short, cinematic video loop or a stunning, high-resolution photo of the venue beautifully set for a reception (e.g., tables with linens, soft lighting, floral centerpieces).

Gallery: Curated, not crowded. 8-12 perfect photos showing food, decor, and happy moments. Large, clickable thumbnails that open in a smooth lightbox.

Interaction:

Subtle animations (e.g., fade-in as user scrolls, smooth hover effects on buttons).

A fixed navigation bar for easy access.

2. Site Structure & Wireframe (The "Minimal" Part)
A single-page scrolling website with a fixed header navigation is ideal for this purpose.

Navigation Bar (Fixed at top):

Logo (Simple text logo or an elegant monogram)

Links: Home | About | Venues | Menus | Gallery | Contact

Call to Action (CTA) Button: "Schedule a Visit" (in the accent color)
